# Developer website assets

`app-ads.txt` must ultimately be reachable at the root of the developer website domain used in the Google Play listing, for example:

`https://example.com/app-ads.txt`

A project page such as `https://username.github.io/repository/app-ads.txt` is not equivalent to a root-domain file if the Play listing points to `https://username.github.io/`.

You can still keep the source in GitHub, but deploy it to a root domain (custom domain, or an appropriate GitHub Pages user/organization site).
