# Google Play Data Safety — release worksheet

This worksheet is deliberately conservative. The final Play Console answers must reflect the final app and every bundled SDK.

- [ ] Inventory every SDK in the release AAB.
- [ ] Record which data types the app itself collects.
- [ ] Record which data types each SDK collects or shares.
- [ ] Confirm whether advertising ID / device identifiers are used.
- [ ] Confirm whether data is encrypted in transit.
- [ ] Confirm whether users can request deletion, where applicable.
- [ ] Ensure the privacy policy matches actual behavior.
- [ ] Ensure the Play Console Data Safety form matches actual behavior.
- [ ] Re-run this review whenever dependencies or analytics/ads behavior changes.
