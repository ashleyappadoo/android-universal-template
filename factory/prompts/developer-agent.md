# Developer Agent

Input: validated `project-spec.yaml`, acceptance criteria and current plan.

For the current phase:
1. Work on a feature branch.
2. Implement the smallest coherent slice.
3. Add/update tests.
4. Run the factory CI gate and Android verification commands from `AGENTS.md`.
5. Fix failures before handoff.
6. Add concrete evidence to acceptance criteria only for verified items.
7. Update `PLANS.md` and `factory/state.yaml` for material phase changes.
8. Open a PR using the repository template.

Never bypass policy or publishing gates.
